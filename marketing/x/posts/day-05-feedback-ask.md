# Day 5 - Feedback Ask

## Goal

Ask for specific feedback that can improve QA-Z without fishing for vanity
metrics.

## Post

```text
Feedback ask for QA-Z:

What evidence would you require before merging AI-generated code?

Examples: tests, lint, Semgrep rules, contract checks, review packets, repair prompts, verification reports.

Repo/issues: https://github.com/qazedhq/qa-z
```

## Optional Thread

```text
1/ Especially interested in failure modes from real agent workflows: auth changes, generated tests, config edits, dependency bumps, and cleanup-only PRs.

2/ Please file concrete ideas or rough notes. The useful unit is a deterministic gate or a repairable failure, not a vague quality slogan.
```

## Link Targets

- Repository and issues:
  [https://github.com/qazedhq/qa-z](https://github.com/qazedhq/qa-z)
- Good first issues:
  [https://github.com/qazedhq/qa-z/blob/main/docs/issues/good-first-issues.md](https://github.com/qazedhq/qa-z/blob/main/docs/issues/good-first-issues.md)

## What Not To Claim

- Do not ask repeatedly for stars.
- Do not imply feedback is already customer validation.
- Do not claim package-registry publishing.
