# Day 2 - Agent Safety

## Goal

Frame QA-Z around deterministic safety gates for AI coding agents.

## Post

```text
Agent safety for code should be boring in the best way:

explicit contracts
deterministic checks
clear failure evidence
repair prompts
post-repair verification

That is the QA-Z alpha thesis.

Repo: https://github.com/qazedhq/qa-z
```

## Optional Thread

```text
1/ QA-Z keeps model-specific behavior behind adapters. The core workflow is contracts, checks, artifacts, and verification.

2/ Safer agent workflows need fewer vibes and more executable gates reviewers can rerun.
```
