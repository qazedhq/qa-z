## Notes

- Daily stars: record the visible repository star count once per day.
- Forks: record the visible repository fork count once per day.
- X impressions: use X analytics if available.
- Profile visits: use X analytics if available.
- Link clicks: record only if available.
- Issues opened: count public GitHub issues opened that day.
- Install/demo failures: summarize concrete failures only.
- Repeated questions: capture wording for a future FAQ.
