# Domain Docs

Matt Pocock engineering skills should consume this repo's domain context in this order.

1. Read root `AGENTS.md`.
2. Read `README.md` for the public QA-Z command contract.
3. Load only the scope-relevant files under `docs/`, especially current reports or release notes when the task touches them.
4. If present, read root `CONTEXT.md` or `CONTEXT-MAP.md`.
5. If present, read relevant ADRs under `docs/adr/`.

This repo is single-context by default. If future work adds `CONTEXT-MAP.md`, follow that map for subsystem-specific context.

Use QA-Z's deterministic evidence vocabulary in issue titles, test names, and hypotheses. If a Matt Pocock skill suggests language that weakens deterministic QA gates, keep the QA-Z repo rule and call out the adaptation.
