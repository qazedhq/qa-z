# QA-Z v0.9.9-alpha

QA-Z `v0.9.9-alpha` is the GitHub prerelease for the AI code
merge-safety surface that landed after `v0.9.8-alpha`.

The target commit is the post-merge `main` commit after PR #9 and PR #10. No
Python package publish is planned for this prerelease step, and the packaged
project version remains `0.9.8a0` until a separate version-bump and publish
decision is made.

## Release Commit

`e9e9c55a7bf6b102b122d88b2c6af4cb81bd782f`

## Highlights

- Repositioned the public README around "Make AI coding safe to merge."
- Added `qa-z guard` as a one-command merge-safety evidence surface.
- Added `qa-z skill install` surfaces for Codex, Claude Code, Cursor, and
  GitHub Copilot.
- Added `qa-z demo auth-bug` and packaged demo resources for installed
  wheel/sdist smoke coverage.
- Added Agent QA Playbook documentation and repair recipe documentation.
- Added GitHub composite action documentation and example workflow coverage.
- Added public raw URL hygiene checks for critical public files.
- Added the `Public Raw Hygiene` GitHub Actions workflow.
- Split quality validation from release-tag preflight so historical
  `v0.9.8-alpha` state does not fail normal quality validation.
- Fixed release-mode gate targeting so final release checks validate the current
  branch instead of stale default-branch state.
