# QA-Z v0.10.0-beta Release Notes Draft

Draft only - not a GitHub Release.

## Summary

QA-Z v0.10.0-beta is planned as a beta readiness milestone for public package
install conversion, release proof discipline, and clearer operator-facing
handoff evidence. `v0.10.0-beta` is not released.

## Key Improvements Since v0.9.9-alpha

- TestPyPI rehearsal proof exists for historical package metadata `0.9.8a0`.
- Source package metadata is aligned to `0.10.0b0` for future production PyPI
  beta preparation.
- Package publish boundaries now distinguish TestPyPI proof from production
  PyPI availability.
- Future PyPI install conversion has explicit readiness, README transition, and
  smoke-plan gates.
- Release documentation keeps tags, GitHub Releases, deployment, and version
  metadata changes separate from docs-only readiness work.

## TestPyPI Proof

TestPyPI proof exists at https://test.pypi.org/project/qa-z/0.9.8a0/

The proof uses historical metadata `qa-z` / `0.9.8a0`. It does not prove
production PyPI availability for `0.10.0b0`.

## Install Status

GitHub source install remains the current public install path.

Production PyPI is not published. Future PyPI install commands must stay
future-only until owner approval, version update, production publish, and install
smoke proof are complete.

The v0.18 production PyPI GO/NO-GO packet
(`docs/reports/v0.18-production-pypi-go-no-go.md`) records
`NO_GO_MISSING_APPROVAL` and keeps README install text unchanged. Local build,
`twine check`, and installed-package smoke passed for `0.10.0b0`, but no
production registry upload occurred.

The v0.19 production PyPI governance packet
(`docs/reports/v0.19-production-pypi-governance.md`) records the future
Trusted Publishing design, required approval flags, workflow draft, and
rollback/yank playbook. No upload occurred in v0.19.

## Known Limitations

- Current source package metadata is `0.10.0b0`.
- TestPyPI proof remains historical for `qa-z==0.9.8a0`.
- README cannot switch to production PyPI install commands yet.
- Production PyPI install smoke proof does not exist yet.
- Production PyPI approval and credential/trusted-publishing proof are still
  missing.

## Release Boundary

This draft does not publish to PyPI, run upload tooling, bump `pyproject.toml`,
make a tag, make a GitHub Release, run deployment, or claim PyPI install
availability.
