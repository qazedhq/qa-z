# v0.21 - First-Run Onboarding

Date: 2026-05-28

Status: local product slice complete.

## Goal

Make a clean `qa-z doctor` result point users to the next local commands instead
of stopping with an empty `next_actions` list.

## Change

Clean doctor next actions now render in JSON and human output:

```text
Run `qa-z demo auth-bug`.
Run `qa-z scorecard`.
Run `qa-z guard --adapter codex --deep auto --fail-on-risk`.
```

This complements the existing `qa-z init --profile auto --dry-run`,
`qa-z demo auth-bug --json`, quickstart, and repair-verify flow without changing
the package publish boundary.

## Validation

- `tests/test_doctor.py::test_passed_doctor_suggests_first_run_next_actions`
  failed first on an empty `next_actions` array, then passed after doctor gained
  the clean-path actions.
- `tests/test_doctor_docs.py::test_v021_doctor_docs_pin_clean_next_actions`
  failed first on the missing v0.21 report, then passed after docs were added.
