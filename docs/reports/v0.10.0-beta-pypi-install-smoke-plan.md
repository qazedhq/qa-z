Future commands after PyPI publish only.

## Expected proof

After a future production PyPI publish, capture:

- exact package version and PyPI project URL;
- clean virtual environment `python -m pip install` result;
- `pipx` install result without using local source paths;
- `uv tool install` result without using local source paths;
- `qa-z demo auth-bug` result from the installed console script;
- confirmation that README and launch docs now match the proven install path.

## Boundary

create a tag, create a GitHub Release, or move README to a live PyPI install
claim.
