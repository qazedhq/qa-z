## Rollback / Yank Considerations

- No-release-yet rollback is trivial because no external release action occurs.
- GitHub prerelease rollback requires an approved policy for deleting, editing,
  or superseding a release and tag.
- TestPyPI and PyPI rollback is registry-owned; use the selected registry yank
  or retention policy instead of assuming a local undo command exists.
- npm or GitHub Packages rollback requires registry-specific policy and package
  ownership confirmation.
- Deploy rollback requires deployment platform ownership, previous artifact
  proof, and incident communication policy.
