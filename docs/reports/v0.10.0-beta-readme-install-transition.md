# QA-Z v0.10.0-beta README Install Transition Plan

Status: future transition plan only.

## Current GitHub source install

The current public install path remains the GitHub source install:

```bash
pipx install git+https://github.com/qazedhq/qa-z.git
uv tool install git+https://github.com/qazedhq/qa-z.git
```

README must keep this source-install posture until production PyPI proof exists.

## Future PyPI install target

After production PyPI beta publish is approved, executed, and verified, README
can switch to version-pinned PyPI commands for the approved package metadata
version. The recommended candidate is `0.10.0b0`, pending owner decision.

## Exact conditions before README can switch

1. Owner approves production PyPI beta publish.
2. Separate version PR updates `pyproject.toml` from `0.9.8a0` to the approved
   metadata version.
3. Production PyPI publish completes for that exact version.
4. PyPI project URL and install proof are captured.
5. README install commands are updated in the same PR as matching public-doc
   truth tests.
6. Release notes stop being draft-only only after a GitHub Release is separately
   approved and created.

## No live PyPI claim yet

README must not contain live `pipx install qa-z` or live
`uv tool install qa-z` until production PyPI publish proof exists for the
selected version.
