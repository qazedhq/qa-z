# v0.22 - Profile And Monorepo Intelligence

Date: 2026-05-28

Status: local product slice complete.

## Goal

Make `qa-z init --profile auto --dry-run` easier to read for first-time users
without breaking the existing init output that scripts and docs already expect.

## Change

The profile detector still reports the legacy compatibility lines:

```text
QA-Z init profile detection: nextjs
confidence: high
evidence: package.json, next.config.js
activated checks: Next.js TypeScript surface, TypeScript fast checks, Semgrep deep checks
next command: qa-z init --profile nextjs
```

It now also prints a readable recommendation block:

```text
Recommended profile: nextjs
Confidence: high
Evidence:
- package.json
- next.config.js
Activated checks:
- Next.js TypeScript surface
Next:
- qa-z init --profile nextjs
```

## Validation

- `tests/test_init_options.py::test_init_auto_dry_run_prints_readable_profile_recommendation`
  failed first on the missing `Recommended profile` line, then passed after the
  init renderer change.
- `tests/test_profile_detection.py::test_auto_dry_run_does_not_write_config_and_explains_evidence`
  confirms the older dry-run output remains compatible.
- `tests/test_public_docs_current_truth.py::test_init_and_doctor_docs_describe_auto_profile_detection`
  failed first on missing docs wording, then passed after the init docs were
  updated.
